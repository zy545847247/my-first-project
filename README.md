# 宝宝探索世界 · 微信小程序 V1

面向亲子共看场景的原生微信小程序交互 Demo。视觉采用奶油白、浅绿、浅黄和天空蓝，保留大触控区域与留白。

## 已实现

- 首页与首页／学习／我的三个 Tab。
- 动物、水果、交通、日常用品、颜色 5 个分类，每类 10 张，共 50 张词卡。
- 中文词名、带声调拼音、简短描述、颜色色块和 Emoji 示意图。
- 图片区域点击动画、音频播放适配器、收藏、上一张／下一张、分类完成提示。
- 设备本地保存昵称、收藏、看过词卡、探索天数与最近词卡。
- 可选 Node.js 只读词汇接口，无 npm 依赖。

## 当前边界

这是可以导入开发者工具的功能 Demo，尚未发布。Emoji 是临时示意素材，不是定制高清卡通插画。50 张词卡的 image/audio 字段目前为空；颜色词卡用真实色块展示。正式录音尚未制作，播放按钮会提示待补充，不会伪装播放成功。宝宝头像暂用固定幼苗图标。

V1 使用本地存储，没有登录、用户数据库或跨设备同步。Node 服务只提供内容数据，前端默认直接使用内置内容，不依赖服务。AI 拍照识别与故事生成尚未实现。打开词卡仅计为“看过”，不表示宝宝已经掌握。

## 最快运行方式

1. 下载仓库 ZIP 并解压，或 `git clone https://github.com/zy545847247/my-first-project.git`。
2. 打开微信开发者工具，选择“导入项目”，选择本仓库根目录（包含 project.config.json）。
3. 本项目默认 AppID 为 `touristappid`。若工具要求 AppID，填写你自己的小程序 AppID。真实预览／上传使用你自己的 AppID。
4. 点击编译，从首页选择分类、打开词卡、收藏，然后查看学习页和我的页。
5. 本项目不需要 npm 构建。用终端运行 `npm test` 检查核心逻辑。

## 可选内容服务

Node.js 20+ 下运行 `npm start`，监听 `127.0.0.1:3000`。

- `GET /health`
- `GET /api/categories`
- `GET /api/words`
- `GET /api/words?category=animals`

服务默认仅本机可访问，不保存儿童资料。若后续改为线上内容服务，需要独立部署 HTTPS 服务，并为小程序配置合法域名。不要将 API 密钥放进前端。用户资料同步需要先补充真实登录和服务端身份校验。

## 替换视觉与声音

在 `miniprogram/data/words.js` 设置每个词的 `image` 和 `audio`。图片可使用本地 PNG（如 `/assets/images/animals-01.png`）或 HTTPS 地址；声音可使用本地 MP3 或配置过域名的 HTTPS 地址。组件优先展示 image，未填写时使用色块或 Emoji。无需修改页面交互。

## 项目结构

```text
miniprogram/
  pages/            首页、分类、词卡、学习、我的
  components/word-art/ 可替换词卡图片与动画
  data/words.js     50 个词条与分类
  services/         本地记录、音频生命周期
server/             可选只读内容服务
tests/              数据、持久化、音频和词卡流测试
docs/               验收步骤和扩展计划
```

## 验证情况

Node 自动检查覆盖词条数量、分类完整性、重复浏览去重、跨日记录、收藏持久化、损坏缓存恢复、音频错误与清理、词卡完成流程。微信开发者工具与真机显示／音频未在当前环境验证，请按 docs/ACCEPTANCE.md 验收。

## 发布

替换 AppID → 补充正式插画与录音 → 开发者工具和真机验收 → 使用开发者工具上传 → 在微信后台完成审核与发布。GitHub 提交不等于小程序已经上线。
